# Плановое обслуживание базы фабрик (автозапуск)

Ты — Claude, работающий в проекте NYTreeToys (`work/own/zavod_NYTreeToys`). Это плановый
запуск по расписанию, владелец может не быть за компьютером: работай полностью автономно,
ничего не спрашивай.

Задача — запустить субагента `nytoys-researcher` лёгким проходом:

1. Закрыть часть меток `[уточнить]` из карточек `research/fabriki/` (сверяясь с первоисточниками).
2. Добавить 2–5 новых фабрик/мастеров ёлочных игрушек, не совпадающих с базой (сверяй по названию и городу).
3. Обновить `research/INDEX.md` (таблица + дата и счётчик внизу).
4. Закоммитить изменения `research/` (локальный git-коммит разрешён всегда; push — никогда),
   трейлер: `Co-Authored-By: Claude Code <noreply@anthropic.com>`.
   Коммитить через обёртку `python panel/commit-safe.py -m "сообщение" research` — она
   сериализует коммиты, если параллельно работают продюсеры панели (иначе возможен
   столк на .git/index.lock); прямой `git commit` не использовать.
5. Отчёт печатается в stdout (попадает в лог `research-scheduled.log` из wrapper-скрипта);
   в карточки и отчёты исследователя его не дублировать.

Границы (действуют безусловно):
- Публикации в соцсети, `.claude/agents`, `posts/` — не трогать.
- `secrets/` не читать, не выносить, не коммитить.
- Если делать нечего (база свежая, ничего не нашлось) — завершиться одной строкой «изменений нет».
