## Изменения к этому запуску (действуют безусловно)

- **Генерация ComfyUI исключена**: субагент nytoys-image НЕ запускать. Вместо него
  запусти субагента `nytoys-fetch-photos` и возьми фото с сайта/паблика источника
  (некоммерческое использование, источник фиксируется в photos[], вариант площадок —
  при публикации).
- **Фото**: если в карточке есть сайт (`sites`) — достаточно спарсить ТОЛЬКО сайт,
  ВК-паблик не открывать (анонимно ВК не отдаёт картинки, из-за таких попыток посты
  не собирались). Если сайта нет — можно попробовать ВК через залогиненный профиль
  `panel/vk-profile` (Playwright, channel="msedge", headless=False). Если фото взять
  неоткуда вовсе — всё равно собери пост (photos пуст) и честно напиши в отчёте
  «нет фото — владелец добавит»: пост формируется и попадает в очередь.
- **Публикация запрещена**: пост остаётся черновиком, владелец рассмотреть его и сам
  решит публикацию через панель. Никаких вызовов nytoys-pub-tg / nytoys-pub-vk.
- Локальный git-коммит поста разрешён (trailer: `Co-Authored-By: Claude Code <noreply@anthropic.com>`).
  Коммить ТОЛЬКО через обёртку: `python panel/commit-safe.py -m "сообщение" <пути>` — она держит
  блокировку, чтобы не столкнуться с параллельными агентами панели на .git/index.lock.
  Прямые `git commit` / Sourcegraph-инструменты для коммита не использовать.
- `secrets/` не читать, не выносить, не коммитить.
